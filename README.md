# Customer-Demographics-Audience-Insights-Dashboard-Excel-GA4

## Project Overview

This project analyzes audience demographics using Google Analytics 4 (GA4) data and Microsoft Excel.

## Tools Used

- Google Analytics 4 (GA4)
- Microsoft Excel

## Dashboard Metrics

- Total Users
- Total New Users
- Total Countries
- Average Engagement Rate

## Analysis Performed

- Age Group Analysis
- Gender Distribution Analysis
- Top Cities Analysis
- Top Countries Analysis
- Device Category Analysis
