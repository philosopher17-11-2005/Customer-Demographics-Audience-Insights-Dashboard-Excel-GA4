# Customer Demographics Audience Insights Dashboard (Excel + GA4)

## Project Overview
This dashboard analyzes customer demographics and audience insights using Google Analytics 4 (GA4) data in Excel.

## Business Problem
The objective of this project is to analyze customer demographics and audience behavior using Google Analytics 4 (GA4) data. The dashboard helps identify key audience segments, user engagement patterns, and opportunities for improving marketing performance and decision-making.

## Dataset Information
- Source: Google Analytics 4 (GA4)
- Data Type: Customer Demographics and Audience Insights
- Tool Used: Microsoft Excel
  
## Objectives
- Analyze audience demographics
- Identify gender distribution
- Understand age group behavior
- Generate actionable business insights

## Tools Used
- Microsoft Excel
- Google Analytics 4 (GA4)

## Key Insights
- TOP 10 Countries-US dominance + Asia Pacific growth signal 
- TOP 10 Cities-Silicon Valley cluster + Singapore per-capita anomaly
- New vs Returning-Strong acquistion but weak retention (13% return rate)
- Gender Distribution-81% unknown data is a critical gap
- Age Group-18-34 cohort owns 67% of users
- Device Category-67% mobile=mobile-first is essential

  ## Recommendations
- Focus marketing efforts on the highest-performing age group.
- Improve engagement strategies for underrepresented user segments.
- Optimize the website experience for mobile users.
- Develop retention campaigns to increase returning users.
